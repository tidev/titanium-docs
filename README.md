# Titanium SDK Documentation

This repo builds the [https://titaniumsdk.com](https://titaniumsdk.com) site using VitePress.

```
docs/
  .vitepress/
    config.js          # VitePress config
    sidebar.mjs        # Auto-generated sidebar
    theme/             # Custom Vue components for API rendering
  api/
    titanium/          # Generated: Titanium SDK API reference
    alloy/             # Generated: Alloy Framework API reference
    modules/           # Generated: Native module API reference
scripts/
  convert.mjs          # Build script: clones sources, converts YAML/JSCA → MD, writes sidebar
```

### Commands

| Command | Description |
|---------|-------------|
| `npm run convert` | Clone sources + generate all markdown + sidebar |
| `npm run dev` | Dev server at http://localhost:5173 |
| `npm run build` | Static build to `docs/.vitepress/dist` |
| `npm run preview` | Preview production build |

### Doc sources

- **Titanium SDK**: YAML files from `tidev/titanium-sdk` (cloned to `titanium-sdk-cache/`)
- **Modules**: YAML files from individual module repos (cloned to `modules-cache/`)
- **Alloy Framework**: JSCA (JSON) from `tidev/alloy` (cloned to `alloy-cache/`)

All markdown is generated by `scripts/convert.mjs`. Do not edit files in `docs/api/` directly — make changes to the source repos instead.
